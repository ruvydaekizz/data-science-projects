# 📊 Data Science Projects

Hoş geldiniz! Bu depo, Veri Bilimi (Data Science), Makine Öğrenimi (Machine Learning) ve Veri Analizi (Data Analysis) alanındaki çalışmalarımı, kişisel projelerimi ve akademik uygulamalarımı bir araya getirmektedir.

Burada, temel Keşifçi Veri Analizi (EDA) çalışmalarından, kapsamlı Makine Öğrenimi modellemelerine kadar farklı karmaşıklık seviyelerinde projeler bulabilirsiniz.

## 📂 Projeler (Projects)

Bu depoda yer alan projelerin kısa özetleri aşağıdadır:

| Proje Adı | Açıklama | Tür |
| :--- | :--- | :--- |
| **🏦 Bank Marketing ML Graduation Project** | Banka pazarlama verileri kullanılarak müşterilerin vadeli mevduat hesabına abone olup olmayacağını tahmin eden makine öğrenimi modeli. (Mezuniyet Projesi) | `Classification`, `ML` |
| **💳 Credit Risk Analysis** | Kredi riskini belirlemek için yapılan kapsamlı veri analizi ve risk tahmin modelleri. | `EDA`, `Risk Analysis`, `ML` |
| **❤️ Heart Disease Risk ML** | Kalp hastalığı riskini tahmin etmek için geliştirilen makine öğrenimi projesi. Sağlık verileri üzerinde sınıflandırma algoritmaları içerir. | `Healthcare`, `Classification` |
| **☕ Coffee Shop Sales EDA** | Bir kahve dükkanının satış verileri üzerinden yapılan Keşifçi Veri Analizi (EDA). Satış trendlerini ve müşteri davranışlarını inceler. | `EDA`, `Visualization` |
| **🛒 Supermarket Sales Basic EDA** | Süpermarket satış verileri üzerinde yapılan temel düzeyde veri analizi ve görselleştirme çalışması. | `Basic EDA`, `Pandas` |

## 🛠️ Kullanılan Teknolojiler ve Kütüphaneler

Bu projelerde ağırlıklı olarak **Python** programlama dili ve aşağıdaki kütüphaneler kullanılmıştır:

* **Veri İşleme:** `Pandas`, `NumPy`
* **Görselleştirme:** `Matplotlib`, `Seaborn`
* **Makine Öğrenimi:** `Scikit-learn`
* **Diğer Araçlar:** `Jupyter Notebook`

## 🚀 Kurulum ve Kullanım

Projeleri yerel makinenizde çalıştırmak için aşağıdaki adımları izleyebilirsiniz:

1.  Bu depoyu klonlayın:
    ```bash
    git clone https://github.com/ruvydaekizz/data-science-projects.git
    ```
2.  İlgili proje klasörüne gidin:
    ```bash
    cd data-science-projects/klasör-adi
    ```
3.  Gerekli kütüphaneleri yükleyin (Genellikle gereksinimler notebook içinde belirtilmiştir):
    ```bash
    pip install pandas numpy scikit-learn matplotlib seaborn
    ```
4.  Jupyter Notebook'u başlatın:
    ```bash
    jupyter notebook
    ```
